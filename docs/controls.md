# Controls

## Main menu

| Input | Action |
|-------|--------|
| ↑ / ↓ | Navigate menu options |
| Enter | Select menu item |
| Mouse | Click buttons |

## Gameplay

| Input | Action |
|-------|--------|
| → | Move right |
| ← | Move left |
| ↑ | Jump |
| P | Pause / unpause |
| Esc | Return to menu |

## Settings

| Input | Action |
|-------|--------|
| F | Toggle fullscreen |
| Esc | Return to menu |

## Puzzle mode

| Input | Action |
|-------|--------|
| 1 / 2 / 3 | Select answer |
| Mouse | Click answer |

A correct answer scores **+20**, a wrong answer **-20**, with a 16-second
time limit per question.

## Connect Four (vs CPU)

| Input | Action |
|-------|--------|
| Click a column | Drop your token |
| R | Quit the minigame |

You play the red tokens; the CPU (yellow) is driven by the
[minimax opponent](connect-four-ai.md).
